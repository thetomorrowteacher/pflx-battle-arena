# PFLX Battle Arena — Title Art & Music Prompt Pack

**How to use:**
1. **Title art (Nano Banana):** paste the image prompt, generate at **16:9 (1920×1080)**, save as `public/games/art/<game-id>.png`. The game auto-detects it and crowns the intro screen with it.
2. **Music (Suno):** paste the style prompt (use it in the Style/Genre box; keep it **instrumental**), download the MP3, save as `public/games/music/<game-id>.mp3`. The game auto-detects it and plays it looped instead of the built-in procedural score. The 🎵 toggle and the host's GAME MUSIC setting still control it.
3. Commit + push both folders — done. No code changes needed, ever.

**Shared art style (append to every image prompt):**
> Cinematic sci-fi video game key art, 16:9, dark navy space backdrop (#04070d) with cyan and gold neon accents, volumetric light, subtle film grain, bold composition with clear focal point, room at the top for a title logo, no text, no watermark, family-friendly, stylized low-poly-meets-cinematic look.

**Shared Suno rule:** instrumental only, loopable (no big intro/outro), 90–120 seconds is plenty.
